# D3D12 runtime tests on Radeon RX 5700 XT

**Final combined build:** Windows x64 Release with [#5](https://github.com/pixl27/ProjectReCity/pull/5), [#6](https://github.com/pixl27/ProjectReCity/pull/6), [#7](https://github.com/pixl27/ProjectReCity/pull/7) and [#8](https://github.com/pixl27/ProjectReCity/pull/8). All **36/36 CTest cases** passed, including synthetic GameInput with SDL 3.4.20. The two Python runner test groups passed **48/48 and 36/36**. Each unfiltered GPU run (native and emulated wave64) translated and validated **102/102 shaders**, passed **92/100 GPU cases**, skipped the same eight unsupported cases and had **zero failures**.

Configure with MSVC x64, CMake/Ninja, Vulkan headers and glslangValidator, enabling `RECITY_D3D12_SHIM_TESTS=ON`. For GameInput we used `RECITY_SDL3_FETCH=ON` and `CMAKE_DISABLE_FIND_PACKAGE_SDL3=ON` to select the pinned static SDL build. [Details of the shared-package configuration issue](https://github.com/pixl27/ProjectReCity/issues/1#issuecomment-7128250691). Build all targets and run `ctest --test-dir <build> --output-on-failure`. For the GPU suite use `python -I scripts/run_gpu_tests.py --build <build>` with `RECITY_W64_EMULATE=0` and then `1`.

## Reproducible failure

`d3d12_vulkan_device_test.exe` returned 1 each time. All 195 format-info queries matched. Among 15 optional-feature queries, the fixture found one difference:

```text
OPTIONS19.SupportedSampleCountsWithNoOutputs: ours 0xf not subset of host 0x1d
line 1861: options_mismatches == 0
```

The shim returns the Vulkan mask for framebuffer sample counts with no attachments. On this adapter, `vulkaninfo` listed 1, 2, 4 and 8 samples. The Windows D3D12 device on the same adapter reported 1, 4, 8 and 16. The comparison rejects the 2-sample bit. The observations are capability queries; neither measures rasterization at those sample counts. The [Microsoft API specification](https://github.com/microsoft/DirectX-Specs/blob/master/d3d/VulkanOn12.md#sample-frequency-msaa-with-no-render-targets-bound) describes the D3D12 guarantee and single-sample fallback. The fixture exits at this assertion, before its later copies, resolves, tiling and query subtests.

## OPTIONS19 retest from source

Built [PR #6 at 1407ecf](https://github.com/pixl27/ProjectReCity/pull/6) for Windows x64 with MSVC 19.44, Windows SDK 26100, CMake and Ninja. In two runs on the same adapter, 195/195 format-info queries and 15/15 feature-option comparisons matched. The shim returned `0x1` for `SupportedSampleCountsWithNoOutputs`. Both runs reached a later copy comparison that the original test had stopped before.

## Whole-resource depth/stencil copies

Two of 69 copy comparisons differed at that later check. For whole-image copies of D32_FLOAT_S8X24_UINT and D24_UNORM_S8_UINT, valid stencil bytes differed inside a row. Native D3D12 agreed with the CPU seed. On the Vulkan path, source and per-plane control readbacks also agreed with the seed. The whole-resource destination differed. Combining aspect masks, splitting calls without ordering writes, and preinitializing the destination did not fix it.

With [PR #8 at 88a1377](https://github.com/pixl27/ProjectReCity/pull/8) applied alongside #6, the depth mip copies are followed by a transfer-write dependency before the stencil mip copies. Two uninstrumented runs of the existing device test returned 0. All 69 copy comparisons passed under the fixture's existing acceptance rules, including its documented BC-format exceptions. All 60 available resolve comparisons matched, and 10 unsupported or host-unavailable cases were skipped. The full test also reached its reserved-resource, tiling and query checks.

Repeating the before/after comparison with Khronos validation 1.4.357.0 and synchronization validation enabled reproduced 2/69 differing cases before and 0/69 after. Neither run emitted a VUID or synchronization-hazard diagnostic. These data establish the effect of the ordering change on this adapter and driver; they do not establish a Vulkan specification violation.

The locally rebuilt `d3d12_descriptor_test.exe` included the optional shader (glslangValidator 16.6.0) and exited 0. Its shader sampled the descriptor table: 64 RGBA8 and RGB9E5 texels matched, the 7×5 BC1 mip passed 64 point samples, all 128 volume texels matched, and the A8/R8 and packed-format comparisons passed. This covers the shader path omitted in the CI binary.

`python -I runtime/test/check_d3d12_trace.py runtime/build/d3d12_gcl8_test.exe` verified 8 ordered trace entries. Running the same script with `runtime/build/d3d12_com_test.exe --queue` verified 65.

These offscreen tests cover parts of the render path leading to presentation. The [M0 acceptance criteria](https://github.com/pixl27/ProjectReCity/blob/main/docs/d3d12_vulkan.md) include presentation, a visible stable clear colour for 60 frames, validation and call tracing. This run did not exercise a window, frame events or PresentX.
